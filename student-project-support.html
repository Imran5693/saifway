Frequently asked questions

Can I ask about a project other than bug hunting?

Yes. This help desk accepts general project inquiries, including Python applications, network engineering, automation, cloud IAM and cybersecurity. Describe your topic so its fit can be assessed.

Can students outside Pakistan contact you?

Yes. Online inquiries are welcome globally. Include your country and time zone so a suitable time can be discussed.

What should I prepare before asking for debugging help?

Include the expected result, actual error, tools and versions, a short description of what you tried and a sanitized repository link if available. Remove passwords, tokens and private data.
