## What this project covers

Use pre-midterm information to estimate academic risk and connect topic-tagged assessment results with learning recommendations.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on Python machine-learning pipelines and dashboard development. See the [related portfolio evidence](/projects/2026-04-24-ml-cyber-attack-detection/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Prepare historical pre-midterm inputs and actual midterm labels.
- Train and evaluate a Decision Tree baseline.
- Display early warnings and topic-based support suggestions.

## Technology and feasibility checks

Historical outcomes and topic-tagged assessments are needed for different parts of the system. Streamlit is an adjacent framework; data availability is the first feasibility check.

## Testing and demonstration evidence

Exclude outcome-derived features from prediction inputs. Validate the warning threshold and verify that recommendations correspond to the assessed topic gaps.
