## What this project covers

Visualize disk-head movement and compare scheduling algorithms using consistent request queues and seek-distance calculations.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on Python logic, Flask interfaces and technical visualization. See the [related portfolio evidence](/network-automation-python/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Validate request queues, disk bounds and initial head position.
- Implement the algorithms required by the approved brief.
- Plot movement and compare results with worked examples.

## Technology and feasibility checks

Algorithm correctness is central. Confirm direction and boundary conventions for each algorithm before drawing comparisons; the tool list alone does not define the required implementation.

## Testing and demonstration evidence

Use hand-calculated cases, repeated requests, empty queues and disk-edge positions. Verify reported total movement against the plotted head path.
