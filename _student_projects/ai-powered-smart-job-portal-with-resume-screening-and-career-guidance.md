## What this project covers

Extract resume information, compare candidates with job descriptions and provide explainable match scores through a Python service.

## Why this matches Imran’s experience

Support fit: **Partial support**. This assessment is based on Python NLP and REST integration experience. See the [related portfolio evidence](/projects/2025-11-21-text-based-emotion-recognition/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Define resume parsing and skills-normalization contracts.
- Develop and evaluate matching and missing-skill explanations.
- Review the REST boundary between the PHP portal and Python service.

## Technology and feasibility checks

The brief requires a PHP/MySQL portal plus a separate Python AI service. Python/NLP support fits the portfolio; full PHP delivery needs additional demonstrated capability.

## Testing and demonstration evidence

Test missing resume fields, malformed files and scoring consistency. Treat match scores as decision support and check for unjustified ranking differences.
