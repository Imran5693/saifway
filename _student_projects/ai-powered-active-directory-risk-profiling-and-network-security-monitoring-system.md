## What this project covers

Create a controlled AD lab, collect Windows events and turn rule-based findings into user and asset risk profiles.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on NOC operations, cloud IAM and the ML cyber-attack detection portfolio. See the [related portfolio evidence](/projects/2026-04-24-ml-cyber-attack-detection/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Configure test users, groups and Windows event collection.
- Store timestamped events and implement explainable risk rules.
- Build authenticated dashboards, event filters and exportable reports.

## Technology and feasibility checks

Agree the monitored event IDs and lab resources first. AI explanations must remain tied to collected evidence; this is a laboratory monitoring project.

## Testing and demonstration evidence

Test failed logins, account changes, access permissions and collector failure. Compare dashboard findings with the original Windows events.
