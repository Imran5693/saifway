## What this project covers

Turn explicit academic rules into explainable course-load recommendations that can be reviewed and approved.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on Flask applications, access control and relational database workflows. See the [related portfolio evidence](/projects/2025-05-04-preowned-goods/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Model course prerequisites and student academic inputs.
- Implement eligibility checks, course prioritization and explanations.
- Build the student-entry and approval workflow.

## Technology and feasibility checks

This is a rule-based system. Confirm the university’s actual advising rules instead of substituting an ML model or invented academic policy.

## Testing and demonstration evidence

Use cases should cover blocked prerequisites, course-load boundaries, conflicting inputs and approval permissions. Trace each recommendation to its rule.
