## What this project covers

Compare text classifiers that label news as potentially fake or potentially genuine and explain the limits of those predictions.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on text classification and machine-learning evaluation experience. See the [related portfolio evidence](/projects/2025-11-21-text-based-emotion-recognition/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Clean and deduplicate article titles and bodies.
- Compare Logistic Regression, Multinomial Naive Bayes and SVM using TF-IDF.
- Present confusion matrices, model comparisons and error analysis.

## Technology and feasibility checks

The brief specifies a Python classification application. A Flask interface would be an additional scope choice, not a stated requirement. Predictions do not independently verify facts.

## Testing and demonstration evidence

Split data before fitting the vectorizer. Examine duplicate leakage and changes in predictions caused by punctuation, spacing and publication topics.
