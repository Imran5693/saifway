## What this project covers

Extract product aspects and classify sentiment toward each aspect instead of assigning one label to an entire review.

## Why this matches Imran’s experience

Support fit: **Conditional match**. This assessment is based on existing text emotion recognition work. See the [related portfolio evidence](/projects/2025-11-21-text-based-emotion-recognition/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Establish an aspect-labelled dataset and baseline.
- Implement aspect extraction and compare sentiment models.
- Build CSV review upload and aspect-level charts.

## Technology and feasibility checks

Transformer fine-tuning and sequence labelling go beyond the demonstrated baseline. Confirm dataset access through the student’s VU account and available compute before accepting the full scope.

## Testing and demonstration evidence

Evaluate extraction and sentiment separately. Include reviews that praise one aspect while criticizing another and report per-aspect errors.
