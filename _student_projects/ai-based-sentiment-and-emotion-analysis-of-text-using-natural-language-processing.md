## What this project covers

Classify sentiment and emotion in submitted text, with prediction history, confidence information and evaluation charts.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on the text-based emotion recognition portfolio. See the [related portfolio evidence](/projects/2025-11-21-text-based-emotion-recognition/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Prepare labelled sentiment and emotion datasets.
- Compare TF-IDF classification baselines and evaluate each label.
- Connect manual text and batch input to a results dashboard.

## Technology and feasibility checks

Check dataset licences, label definitions and language coverage before training. Confidence scores need careful interpretation and do not establish a person’s actual emotional state.

## Testing and demonstration evidence

Keep test records separate from preprocessing and training. Report per-class precision, recall, F1 and examples of misclassified text.
