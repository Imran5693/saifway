## What this project covers

Detect English writing errors, let users review individual corrections and export corrected documents while preserving paragraph order.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on NLP pipelines and Python web application experience. See the [related portfolio evidence](/projects/2025-11-21-text-based-emotion-recognition/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Accept text and DOCX input with safe validation.
- Classify writing errors and show explanations and suggestions.
- Apply accepted corrections and generate a corrected DOCX.

## Technology and feasibility checks

LanguageTool integration and document processing need a prototype. Preserve the original text so users can inspect every suggested change.

## Testing and demonstration evidence

Test accepted and rejected edits, overlapping suggestions, punctuation and multi-paragraph documents. Compare exported text order against the source.
