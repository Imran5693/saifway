## What this project covers

Connect knowledge-based AI support with ticket escalation, support-agent replies and resolution tracking.

## Why this matches Imran’s experience

Support fit: **Partial support**. This assessment is based on support operations, REST integration and authentication concepts. See the [related portfolio evidence](/network-automation-services/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Model ticket lifecycle, permissions and knowledge-base records.
- Review AI integration and human escalation behaviour.
- Define analytics, validation and API troubleshooting checks.

## Technology and feasibility checks

The official backend is PHP 8 with Laravel. The portfolio demonstrates Python/Flask rather than Laravel; offer requirements, API and debugging guidance only unless that skill gap is resolved.

## Testing and demonstration evidence

Test role separation, ticket ownership, unhelpful AI responses, escalation and status transitions. Confirm users can reach a human when automated support fails.
