## What this project covers

Manage student fees, scholarship adjustments, instalments, receipts and outstanding balances in a desktop application.

## Why this matches Imran’s experience

Support fit: **Strong match**. This assessment is based on Python programming, data modelling and access-control workflows. See the [related portfolio evidence](/projects/2025-05-04-preowned-goods/). This is a proposed support topic, not a claim that this exact project has already been delivered.

## Main modules to plan

- Model students, departments, fee structures and scholarships.
- Implement accountant, administrator and student access.
- Calculate balances and create receipts and collection reports.

## Technology and feasibility checks

The brief requires a Tkinter desktop application, not a Flask website. Tkinter is an adjacent skill; prototype the GUI and printing workflow before committing to delivery.

## Testing and demonstration evidence

Check scholarship percentages, late fines, partial payments and repeated receipt actions. Use decimal arithmetic and reconcile every balance with payment history.
